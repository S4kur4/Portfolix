# 持仓语音输入

在添加／编辑持仓或更新持仓窗口中，先选中可编辑字段，按住 **Fn** 说话，松开后等待识别结果填入。录音期间字段显示主题紫色高亮和随声音变化的波形。识别内容会替换该字段，保存前仍可手动修改；不会自动提交持仓。

首次使用需要 macOS 麦克风与语音识别授权。如果授权弹窗打断按键，请完成授权后再次按住 Fn。中文界面使用普通话识别，英文界面使用美式英语识别。仅使用 Apple Speech 支持的本机识别，不保存录音，不通过 DeepSeek 识别；当前语言的本机识别不可用时保留原值并提示。

数字字段支持识别出的数字、小数及明确的中文数字表达。建议逐位读出数字和小数点；不明确的口语、省略单位或带有多组数字的内容会被拒绝，不猜测金额。识别失败、超时、切换字段、手动修改内容、关闭窗口或切到其他 App 时，未提交的语音结果不会写入。单次录音最长 30 秒，松开后最多等待 5 秒取得最终结果。

不会解除已有资产身份锁定或现金成本价锁定。所有语音结果继续使用原来的份额、成本联动和保存校验。

## 实机验证

- 首次授权、拒绝授权、授权弹窗出现时松开 Fn。
- 中文／英文资产名称及数字、小数、长份额；无声和模糊数字。
- Fn 按住／松开、连续输入两个字段、录音时点击其他字段或手动输入。
- 更新持仓中的份额、成本价、总成本联动，以及现金的锁定字段。
- 麦克风切换／拔出、离开 App、关闭编辑窗口。

Fn／地球键可能还被系统用于切换输入法、表情或听写。App 只监听前台本地按键，不安装全局键盘监听，也不改动系统快捷键。不同键盘和系统 Fn 配置下是否存在冲突需要实机验证；不能保证接管所有系统保留行为。

参考：[Apple 本机语音识别](https://developer.apple.com/documentation/speech/sfspeechrecognizer/supportsondevicerecognition)。
